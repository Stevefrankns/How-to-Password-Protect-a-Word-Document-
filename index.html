How to Password Protect a Word Document

Password protection in Microsoft Word can mean two different things: encrypting the file so a password is required to open it, or restricting editing so people can read the document but cannot freely change it. This guide separates those options so you choose the protection that actually matches your goal.

Quick answerIn Word for Windows, use File → Info → Protect Document → Encrypt with Password, enter and confirm the password, then save the document. On Mac, use Review → Protect → Protect Document and configure the password under Security. Word for the web cannot add password encryption to a document; use the desktop app instead.

Choose the right protection

Password to Open vs Restrict Editing

These are not interchangeable. If you need to stop an unauthorized person from reading the document at all, use Encrypt with Password. If people should be able to open and read the document but you want to limit changes, use Restrict Editing or another permissions-based control.

ProtectionWhat it doesBest for
Password to openEncrypts the Word document so the password is required before the document opens.Confidential documents stored or sent outside a controlled collaboration system.
Restrict EditingControls whether readers can edit or what kinds of edits they can make.Forms, policies, templates, and documents that should stay readable.

Important: Marking a file read-only is not the same as encrypting it. A read-only setting can discourage or limit editing, but it is not a substitute for a password-to-open requirement.
Word for Windows

How to Password Protect a Word Document on Windows

  1. Open the Word document in the desktop version of Microsoft Word.
  2. Select File, then Info.
  3. Select Protect Document.
  4. Choose Encrypt with Password.
  5. Enter the password, select OK, then enter the same password again to confirm it.
  6. Save the document. Saving is required for the password protection to take effect.
Keep the password somewhere safe. Microsoft states that Word cannot recover a forgotten document password for you. In managed organizations, an administrator may have a recovery option only if a recovery system such as DocRecrypt was configured before the document password was created.

For the current Microsoft procedure, see Protect a Word document with a password.

Word for Mac

How to Password Protect a Word Document on Mac

Word for Mac exposes the protection controls differently from Word for Windows.

  1. Open the document in Word for Mac.
  2. Go to Review → Protect → Protect Document.
  3. Under Security, choose whether the password is required to open the document, modify it, or both.
  4. Enter the requested password again to confirm it, then select OK.
  5. Save the file and test it by closing Word and reopening the document.

This Mac workflow is distinct from the Windows File → Info path, so instructions written for one platform should not be copied blindly to the other.

Word for the web

Can You Password Protect a Word Document Online?

Not with Word for the web itself. Microsoft says the web version cannot password-encrypt a document and cannot edit a password-encrypted document. If you are working in the browser, use Open in Word and apply the password in the desktop application.

This is an important compatibility point for files stored in OneDrive or SharePoint: storing a document in the cloud does not automatically mean the browser version can create or edit password encryption.

Editing controls

How to Restrict Editing Without Blocking the Document From Opening

If recipients should be able to read the document but not freely change it, use Word's editing restrictions instead of password-to-open encryption.

  1. Open the document and go to Review → Restrict Editing.
  2. Under editing restrictions, select the type of editing you want to allow. For a read-only result, choose No changes (Read only).
  3. Select Yes, Start Enforcing Protection.
  4. Optionally set a password so only someone who knows it can stop the protection.
An editing-restriction password protects the restriction setting. It is not the same as encrypting the document with a password that must be entered before the file can be opened.

Microsoft's current instructions are in Make a document read only in Word.

Owner workflow

How to Remove a Password From a Word Document

If you know the current password, removing password-to-open protection is straightforward in Word for Windows:

  1. Open the document and enter the existing password.
  2. Go to File → Info → Protect Document → Encrypt with Password.
  3. Delete the password from the password box.
  4. Select OK and save the document.

This owner-recovery workflow is intentionally different from attempting to bypass or crack a password you do not know.

See Microsoft's Remove a password from a document.

Recovery

What If You Forget the Word Document Password?

For an ordinary password-protected Word document, Microsoft says Word cannot recover the forgotten password. That makes password management part of the protection process, not an afterthought.

  • Store the password in a reputable password manager or another secure location.
  • Keep an unencrypted recovery copy only if your security policy permits it, and protect that copy appropriately.
  • For business environments, ask IT whether organizational recovery tooling was configured before the file was encrypted.
  • Do not treat obscure password-removal websites as a safe recovery plan for confidential documents.
If you do not know the password, this guide does not provide password-cracking or bypass instructions. Use legitimate owner recovery, backups, or your organization's authorized recovery process.
Sharing & compatibility

Before You Email or Share a Password-Protected Word File

Send the password separately

If you send the document and its password through the same compromised channel, the password adds much less protection. Use a separate trusted channel when practical.

Test the protected copy

Close the file, reopen it, and confirm the password prompt appears before you send the document.

Consider cloud permissions

For ongoing collaboration, identity-based permissions in Microsoft 365 may be easier to manage than distributing one shared document password.

Keep compatibility in mind

Password-encrypted documents require compatible desktop Word software. Word for the web cannot create or edit password-encrypted Word documents.

Practical details

Password Protection Details That Prevent Common Mistakes

Use a password that is strong but recoverable by you

Microsoft documents that Word document passwords are case-sensitive and that ordinary forgotten document passwords cannot be recovered by Word. That makes the password itself part of your document-retention plan. Avoid short, predictable passwords based on names, dates, company names, or document titles. If the file matters long term, store the password in a reputable password manager or another approved secure system rather than relying on memory alone.

Save after adding or removing the password

A surprisingly common failure is configuring the password and then closing the file without saving the protected version. After setting a password, save the document, close Word, reopen the file, and confirm that the password prompt appears. Use the same test after removing a password: close and reopen the saved document to verify that the prompt is gone.

Password-to-open and password-to-modify solve different problems

On Mac, Word exposes separate options for requiring a password to open the document and for requiring a password to modify it. A password to open is the stronger confidentiality boundary because the file cannot be read normally without authentication. A password to modify is useful when recipients should be able to read the document but only authorized people should change it. Do not describe the second option as full document encryption.

Word for the web is not a replacement for desktop password encryption

If a document is stored in OneDrive or SharePoint, the browser interface still does not add Word password encryption. Microsoft says Word for the web cannot password-encrypt a document and cannot edit a password-encrypted document. For ongoing collaboration, cloud sharing permissions may be more manageable than distributing one shared password. For a standalone confidential file, use the desktop Word app when password-to-open encryption is required.

Be careful when sending a protected document by email

Encrypting the Word file helps if the attachment is copied or forwarded, but the password should not automatically travel beside it in the same message. When the sensitivity of the document warrants it, send the password through a separate trusted channel. Also confirm that the recipient has a compatible desktop version of Word before relying on this workflow.

Removing protection requires the current password

Searches such as “remove Word document password” often mix two very different situations. If you know the password, Word provides a normal owner workflow: open the file, return to Encrypt with Password, clear the field, and save. If you do not know the password, that is not the same workflow. Use backups, the document owner, or an authorized organizational recovery process rather than treating password bypass as routine maintenance.

For organizations, permissions may be better than shared passwords

When several people need controlled access, Microsoft 365 sharing permissions, SharePoint controls, or Information Rights Management can be more appropriate than one password that everyone shares. Password-encrypted files are best suited to cases where the file itself needs a portable access barrier. Identity-based controls are usually easier to revoke, audit, and change as team membership changes.

Keep a recovery copy only when policy allows it

An unencrypted backup defeats the purpose of password protection if it is stored in an equally exposed location. If you keep a recovery copy, place it in a location protected by appropriate access controls. In business environments, follow retention and data-handling rules rather than inventing a personal backup method for sensitive company documents.

Common questions

Frequently Asked Questions

How do I password protect a Word document?

In Word for Windows, go to File → Info → Protect Document → Encrypt with Password, enter and confirm the password, then save the file.

Can I password protect a Word document on Mac?

Yes. In Word for Mac, use Review → Protect → Protect Document, then configure the Security password to open, modify, or both.

Can Word Online add a password to a document?

No. Microsoft says Word for the web cannot password-encrypt a document. Open the file in the desktop Word application to add password protection.

Is Restrict Editing the same as password encryption?

No. Restrict Editing controls changes to the document. Password-to-open encryption prevents the document from opening until the correct password is supplied.

How do I remove a Word document password?

If you know the current password, open the document, return to Encrypt with Password, clear the password field, select OK, and save the file.

What happens if I forget the password?

Microsoft says Word cannot recover an ordinary forgotten document password. Organizational recovery may be possible only where administrators configured appropriate recovery tooling in advance.

The Bottom Line

If your goal is confidentiality, use Word's password-to-open encryption in the desktop app. If your goal is collaboration control, use Restrict Editing or Microsoft 365 permissions instead. Whichever method you choose, save the file, test the result, and keep the password or recovery plan in a secure place.

This guide covers legitimate document-owner protection and recovery workflows. It does not provide password-bypass instructions.
